# Multi-floor multi-AGV scheduling

This repository contains a Python implementation of prioritized multi-AGV job
assignment and collision-free routing, based on Guo et al., ICARCV 2024, plus
multi-floor layouts and a hybrid planner. The hybrid uses a central server for
job assignment and lift reservations and one floor server per floor for local
route-leg planning. Lift lobbies provide waiting points at each landing. The
independent `verify()` checker checks generated plans.

## Repository map

- `agv_code/agv_code/` — Python source, pinned dependencies, tests, and generated
  experiment outputs (each in a settings-encoding folder such as
  `results_hybrid_100j_20a_s1-10_strict/`; never a shared default folder).
- `agv_code/agv_code/agv_core.py` — Algorithms 1–3, plan verification, and
  metrics.
- `agv_code/agv_code/agv_hybrid.py` — central lift booking and floor-server
  routing.
- `agv_code/agv_code/agv_layouts.py` — single-floor and three-floor layouts.
- `agv_code/agv_code/agv_compare.py` — A/B/B2/C/WA comparisons and fleet sweeps.
- `agv_code/agv_code/agv_wait_adjust.py` — priority-ordered safe-interval wait adjustment
  with waits allowed at route nodes.
- `agv_code/agv_code/agv_statistical_experiments.py` runs paired light-load and 30-seed
  comparisons; `generate_latex_tables.py` regenerates bootstrap/Wilcoxon summaries and
  booktabs tables from its raw CSV.
- `agv_code/agv_code/sweep_job_scale.py` and
  `agv_code/agv_code/sensitivity.py` — job-scale and parameter-sensitivity
  experiments.
- `agv_code/agv_code/lobby_capacity_sweep.py` — finite lobby-capacity comparison
  on three- and five-floor layouts.
- `agv_code/agv_code/make_manifest.py` — writes `results_manifest.json` (command,
  git commit, seeds, jobs, AGVs, track rule, date, Python/package versions, CPU model
  for every result folder).
- `agv_code/agv_code/make_paper_numbers.py` — writes `paper/generated/numbers.tex`
  and the LaTeX table bodies, every value re-derived from the result CSVs.
- `agv_code/agv_code/check_paper_numbers.py` — fails if any result numeral in the
  paper is hard-coded instead of a macro from `numbers.tex` or a generated table.
- `agv_code/agv_code/make_paper_gantts.py` — regenerates the seed-7 Gantt figures,
  verifying every plan and cross-checking metrics against `comparison.csv`.
- `agv_code/agv_code/make_architecture_figure.py` — architecture diagram.
- `agv_code/agv_code/results/`, `agv_code/agv_code/results_hybrid/`,
  `agv_code/agv_code/results_same_direction/`,
  `agv_code/agv_code/results_scale/`,
  `agv_code/agv_code/results_sensitivity/`,
  `agv_code/agv_code/results_lobby_capacity/` — generated outputs for the demo,
  architecture comparison, track-rule comparison, job sweep, sensitivity sweep,
  and lobby-capacity sweep (`results_lobby_capacity/`).
- `paper/paper_short.pdf` — compiled 6-page short paper (IEEEtran, two columns).
- `paper/paper_full.pdf` — compiled full paper (IEEEtran, two columns).
- `paper/short/` — short-paper source (`main.tex` + `sections/`).
- `paper/full/` — full-paper source (`main.tex` + `sections/`).
- `paper/generated/` — `numbers.tex` and table bodies, regenerated from result CSVs
  by `make_paper_numbers.py`; never hand-edited.
- `paper/figures/` — Gantt and architecture figures, regenerated by
  `make_paper_gantts.py` and `make_architecture_figure.py`.
- `paper/references.bib` — bibliography.
- Root `Prioritized_Planning_for_Large-Scale_Multiple-AGV_Scheduling_Problem_in_Smart_Manufacturing.pdf`
  — the reference paper (Guo et al., ICARCV 2024).
- `REPRODUCIBILITY.md` — environment, exact commands, and full artifact runner.
- `run_all.sh` — one-command regeneration and verification script.

## Reproduce the paper

From the repository root, with Python 3.11 or 3.12 (dependencies pinned in
`agv_code/agv_code/requirements.txt`):

```bash
bash run_all.sh
```

This regenerates every result folder, `results_manifest.json`, `paper/generated/`,
`paper/figures/`, runs `check_paper_numbers.py` and the unit tests, and compiles
`paper/paper_short.pdf` (6 pages) and `paper/paper_full.pdf`. Any failure exits
non-zero. See `REPRODUCIBILITY.md` for the complete command list and the tested
machine details.
